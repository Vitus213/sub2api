# Tasks

每项 checkbox 都是可独立验收的垂直切片，必须引用准确的 Requirement/Scenario，并给出真实验证命令。切片应包含该行为所需的测试、最小实现和验证，不把数据库、service、controller、测试拆成互不交付价值的水平任务。

## 1. 首个可观察行为切片

- [ ] 1.1 [Requirement: 使用准确名称；Scenario: 使用准确名称] 先运行行为测试观察预期 RED，再完成该场景的最小实现并得到 GREEN；验证：`填写仓库可运行的目标测试命令`

## 2. 后续行为与错误路径

- [ ] 2.1 [Requirement: 使用准确名称；Scenario: 使用准确名称] 完成另一个可独立验收的行为或错误路径；验证：`填写仓库可运行的目标测试命令`

按依赖顺序继续编号。每个切片完成后记录 RED/GREEN 证据；规格不完整或实现发现行为冲突时，停止当前 task，先回写 change 并重新确认。
